# Pushkar Sehrawat — Portfolio v2

A premium, editorial-style personal developer portfolio built from the information Pushkar provided.

## Run locally

This version is a static HTML/CSS/JS prototype, so you can simply open `index.html`.

For a local dev server:

```bash
python -m http.server 5173
```

Then open http://localhost:5173

## Deploy

Drop this folder into a GitHub repository and import it into Vercel.
